# Voxum Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Prosa into "Voxum". The app gets:
- a new name;
- a UI and dictation in 5 languages (en, pt-BR, es, fr, zh-Hans; more later);
- a configurable dictation key;
- a question mode;
- file transcription;
- Sparkle updates from a public GPL-3.0 GitHub repo.

**Architecture:** Keep the existing layers:
- `TranscricaoCore`: pure logic and XCTest.
- `TranscricaoEngines`: WhisperKit and MLX.
- `Transcricao`: the AppKit/SwiftUI app.
- `tcli`: the eval command-line tool.

New pure rules go in Core with tests. App wiring goes in the app target. User-visible strings go in a String Catalog.

**Tech Stack:** SwiftPM (swift-tools 5.10), Xcode 27, macOS 14+, Apple Silicon, WhisperKit, mlx-swift-lm (Qwen3-4B-Instruct-2507-4bit) and Sparkle 2.

**Spec:** `docs/superpowers/specs/2026-10-14-voxum-design.md` (authoritative). The earlier specs in `docs/superpowers/specs/2026-10-13-*.md` still apply wherever this spec does not override them.

## Global Constraints

- **User-visible name.** The app's user-visible name is exactly `Voxum`. The bundle id is `io.github.gsb05br.voxum` and the Logger subsystem is `io.github.gsb05br.voxum`.
- **Internal names.** Internal target and module names (`TranscricaoCore`, `TranscricaoEngines`, `tcli`) may stay. The `Transcricao` app target may stay, but the product executable inside the bundle is `Voxum`.
- **Unchanged pt-BR prompt.** The pt-BR no-selection prompt must stay byte-identical. The existing SHA-256 test (`testNoSelectionPromptIsUnchanged`) must stay green and unmodified.
- **Eval floors.** Eval baselines must not regress: pt-BR cases 38/43 and holdout 15/15, from `swift run -c release tcli eval fixtures/cases.json` and `fixtures/holdout.json`.
- **Supported languages (v1, user decision 2026-10-14).** The 5 supported languages, in this order, are:
  - `en` (English, base)
  - `pt-BR` (Português (Brasil))
  - `es` (Español)
  - `fr` (Français)
  - `zh-Hans` (简体中文)

  de, it, ja, ko, hi, ru and ar are deferred. The infrastructure stays generic: adding a language later means a new
  `.lproj`, an `Examples_<code>.swift`, fixtures and one `AppLanguage` case, with no other change.
- **Hotkey choices.** Keys offered for dictation and question mode:
  - right ⌥ (keyCode 61), the default for dictation
  - right ⌘ (54)
  - right ⇧ (60)
  - Fn/🌐 (63, `.function` flag)

  Question mode can also be "Off", which is its default. The two keys can never be equal.
- **Updates feed.** `https://github.com/GSB05BR/voxum/releases/latest/download/appcast.xml`.
- **No secrets or personal data in tracked files.** That covers private keys, tokens, the signing identity string, e-mail, real name, the home folder path, the signing team ID and the old bundle id. The single exception is the old bundle id as the migration source domain (the migration constant), which may appear only in the migration code and its test. The signing identity comes from the git-ignored `scripts/local.env`, with ad-hoc `-` as the fallback.
- **License.** GPL-3.0-or-later. Third-party notices go in `THIRD_PARTY_NOTICES.md` and on an in-app "Credits" screen.
- **Hard rules for agents:**
  - Never send ⌘C, ⌘V, ⌘Z or other keystrokes to other apps on this Mac.
  - Never change the user's clipboard.
  - Never close other apps' documents.
  - Never delete models.
  - Never use `pkill -x Prosa` or `pkill -x Voxum`. Kill only PIDs you launched.
  - Never install to /Applications.
  - Never push to GitHub or create repos/releases, except in Task 8 and only via the controller.
- **Before every commit:** `swift test` is green and `bash scripts/build-app.sh` builds with 0 Swift warnings.
- **Commit trailer.** Commits end with: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

1. **Migration on first launch of the renamed app.** (Removed before the public release, by the user's decision: the only installation had already migrated, and the old bundle id held a personal name.) The models folder must be moved, not re-downloaded, and settings carried over. If the destination already exists, nothing is moved. A crash mid-migration must not lose the models.
2. **A hotkey that is also a modifier.** Right ⌘ used for ⌘C, or right ⇧ used for a capital letter, must never start a dictation, play the start sound or capture a selection. Fn pressed alone must work.
3. **Dictation language "Automatic".** A short clip that Whisper detects as the wrong language must not get its text translated by the LLM. The output language follows the transcript, never the UI language.
4. **Long translations and CJK text.** French strings are long and Chinese ones dense: no clipped or overlapping text in the HUD pill, answer panel, setup window or menus. CJK scoring counts per character.
5. **Concurrency.** Question mode, file transcription and dictation share the models and the clipboard. No overlap may paste into the wrong place, keep a model lease forever, or crash. A dictation started during a file transcription is refused with a HUD message.

### Task 3: Per-language fan-out (4 agents in parallel, one git worktree each)

The controller creates one worktree per language from feat/parlance after Task 2:
`git worktree add ../voxum-wt/<code> -b lang/<code>` for en es fr zh-Hans (en has no
`.lproj` to translate, only examples, cases and audio). One agent per worktree, all dispatched at the same time.

**Each agent may only create or modify:**
- `Sources/Transcricao/Resources/<code>.lproj/*` (translate every key of `en.lproj`, with natural UI wording;
  placeholders kept exactly);
- `Sources/TranscricaoCore/Text/Examples/Examples_<code>.swift` (native-quality few-shot examples; they must not copy
  eval inputs);
- `fixtures/cases-<code>.json` (at least 8 cases: filler, self-correction, list, dictated question, composition
  command, selection edit, read-only answer, proper noun), `fixtures/holdout-<code>.json` (2 cases, written
  BEFORE tuning and committed first), `fixtures/audio/<code>/` (3 `say -v <voice>` phrases, 16 kHz mono LEI16 via
  `afconvert`, plus `refs.json`);
- `docs/lang/<code>.md` (its eval results and notes).

Anything else (shared rules, Core code, other languages) is off limits. A needed shared change is reported, not
made.

**Each agent:**
1. Builds its worktree (`swift build -c release`; first build takes several minutes).
2. Runs `scripts/with-eval-slot.sh swift run -c release tcli eval fixtures/cases-<code>.json --lang <code>` and
   the holdout, and tunes only its examples. Target: ≥80% of the cases and zero answered questions.
   The cases must include one transcript labelled with the wrong language (use the `langConfidence` field) that must
   come back untranslated, and one in-sentence "new line" ("a new line of products") that must stay as text.
3. Measures the Whisper WER on its audio, in fixed and Automatic mode.
4. fr/zh-Hans: checks truncation with screenshots (`-AppleLanguages '(<code>)'` as a launch argument on its own
   `build/Voxum.app`, killing only its own PID). en/es: one screenshot of the main window.
5. Commits on `lang/<code>` and reports: the scores, whether it is "beta", and any shared change it needs.
